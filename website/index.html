提交反馈
文件会上传到服务器吗？+

桌面应用的扫描、比较、合并和导出都在本机完成，不上传文件内容。官网提供产品介绍、界面预览和下载入口，不接收比较文件。

wiiMerge 免费吗？+

免费，源代码以 MIT 许可证公开。你可以在 GitHub 查看代码、问题记录和构建过程。

Excel 比较需要安装 Office 吗？+

不需要。支持 .xls、.xlsx 和 .xlsm，也支持 XLS 与 XLSX 之间比较。可按单元格位置或指定主键列匹配，比较内容与公式 / 缓存值；不比较样式、图表或宏，也不会重新计算公式。

支持哪些压缩包？能直接比较 JAR 和 WAR 吗？+

支持 ZIP、WAR 和 JAR，包括最多三层嵌套归档。可以在树中展开，或在独立差分窗口双击进入新 Tab。同名重复条目会按出现序号分别比较。目前不支持 RAR、7z 或加密归档。

保存合并结果前，会保留原文件吗？+

覆盖原文件前会创建备份，并检查文件是否已被其他程序修改。文本保存保留目标侧编码与换行符。归档中的文本通过「另存为」保存，不会自动回写或重新打包归档。

下载后怎么运行？缺少 WebView2 怎么办？+

请完整解压 ZIP，再运行其中的 wiiMerge.exe，不要只复制启动器。精简版需要 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.8，Windows 11 通常已具备；缺少 WebView2 时应用会提供微软官方安装入口。不能安装这些组件时可选择 Electron 兼容版。

为什么下载需要登录 GitHub？+

当前安装包存放在 GitHub Actions 的 Artifacts，需要登录 GitHub 后下载。构建产物有保留期限；如果旧版下载已过期，可从仓库的 Actions 页面查找较新的成功构建。程序是未签名的便携开发版。
